**Cohort:** 2027 Summer Analysts  
**Curriculum:** Capital Mastery Standard 2.0 + Firm Layer  
**Learners:** 12  
**Report purpose:** identify demonstrated strengths, unresolved readiness gaps and the manager actions most likely to improve the cohort before Day 1.

## Example Manager Attention Queue

### 1. Model Review — cohort-level signal

**Why surfaced:** Model QA is the lowest recurring competency.  
**Evidence:** repeated formula/check errors across several Role Lab submissions.  
**Suggested manager action:** run a short reviewer-led model-QA session using the same error categories that appeared in learner work.  
**What to recheck:** revised downside cases and model checks before launch.

### 2. Learner A — repeated revision signal

**Why surfaced:** two Role Lab revisions.  
**Evidence:** recurring model-check and valuation-support comments.  
**Suggested manager action:** review one revised workbook and ask the learner to explain their check process rather than simply resubmitting a corrected number.

### 3. Learner B — incomplete evidence signal

**Why surfaced:** high baseline score but incomplete professional evidence.  
**Interpretation:** strong diagnostic knowledge is not the same thing as demonstrated job readiness.  
**Suggested manager action:** require completion of the missing work product before treating the learner as ready.

### 4. Learner C — deadline signal

**Why surfaced:** Professional Readiness Final overdue.  
**Suggested manager action:** confirm completion plan and determine whether the delay reflects scheduling or an unresolved skill gap.

## Example learner evidence drill-down

**Learner:** Analyst 07 — synthetic  
**Overall readiness:** 81  
**Evidence coverage:** 100%  
**Role Lab:** 86 after one required revision  
**Professional Final:** 84  
**Lowest competency:** Model QA — 70

### Evidence trail

1. **Baseline diagnostic** — identified strong valuation knowledge but weak model-error detection. Baseline carries 0% credential weight.
2. **Essentials** — passed standardized applied assessment.
3. **Applied Skills** — produced role-format valuation/model work.
4. **Role Lab first submission** — recommendation was directionally correct, but downside checks were incomplete.
5. **Manager/reviewer feedback** — required explicit downside validation and corrected model checks.
6. **Role Lab revision** — passed after the learner corrected the work and documented the changed conclusion.
7. **Professional Final** — passed, while Model QA remained the lowest competency.

### Suggested handoff

**Ready with targeted coaching.** Permit normal analyst onboarding, but have the first live model receive deliberate reviewer attention around checks and downside-case integrity.

The important output is not the label alone; it is the traceable reason behind the recommendation.

## Track interpretation

This example is for **Professional Readiness**, so the report includes Role Lab, revision, final-assessment and full evidence-coverage signals.

A **Career Skills Program** report should not imply that those advanced requirements were completed. It should report the verified Foundations, Essentials and Applied Skills evidence plus the practical Career Skills completion state, clearly labeled as the shorter preparation track.

## Credential / readiness interpretation rule

A diagnostic is a baseline, not job readiness. Professional Readiness is supported by:

- prerequisite verified credentials;
- required Role Lab work;
- revision evidence where applicable;
- competency evidence;
- complete professional evidence coverage;
- critical competency floors;
- the standardized Professional Readiness Final.

A learner can therefore be **complete but not ready**, or can have a strong average while still failing a required critical floor.

## Export / privacy boundary

Employer exports are intended to support coaching and program review, not to expose assessment secrets. Protected answer keys and hidden grading rules remain excluded.

CSV export cells are serialized defensively so learner-controlled spreadsheet-formula prefixes are neutralized before the file is opened in spreadsheet software.

## Recommended manager discussion

At the end of a pilot, avoid asking only “What was the average score?” Ask:

1. Which work-product weaknesses repeated across the cohort?
2. Which learners changed materially after revision?
3. Did the attention queue match where managers would have spent time?
4. Which evidence would you want to see before assigning live work?
5. Did the program reveal gaps early enough to coach them before Day 1?
6. Which parts of the Firm Layer made the standardized training more relevant to the firm's actual process?

That conversation is the intended value of the readiness report: **turn training evidence into specific manager action.**
