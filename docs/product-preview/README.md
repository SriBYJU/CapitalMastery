This folder is intentionally committed so the founder can review the shipped visual system without clicking through every pathway.

- `01-brand` — approved brand board, logo mark, horizontal wordmark and credential seal
- `02-homepage` — desktop homepage
- `03-login` — pre-Firebase account screen
- `04-dashboard` — learner passport/dashboard
- `05-career-pathway` — career directory and flagship pathway
- `06-learning` — foundations/technical/research methodology
- `07-quizzes` — part assessment and 20-question final
- `08-applied-work` — applied assignments
- `09-job-simulation` — inbox/workspace/results
- `10-completion` — certificate-earned celebration
- `11-certificates` — all three certificate tiers
- `12-credentials` — credential dashboard/detail
- `13-linkedin-sharing` — LinkedIn helper and post generator
- `14-founder` — About the Founder
- `15-admin` — QA/admin dashboard
- `16-mobile` — responsive key screens

Screenshots use a fictional QA learner name. No admin password, Firebase secret or real learner data is included.
