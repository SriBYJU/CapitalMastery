# Credential System

Each of the 16 career pathways offers three certificates.

## 1. Foundations Certificate
Issued after Parts 1–2 are completed and the required assessments meet the 80% standard.

## 2. Applied Skills Certificate
Issued after Parts 1–4 are completed and every required assessment meets the 80% standard.

## 3. Career Certificate
Issued only after:

- 100% required pathway completion
- every required knowledge assessment ≥80%
- simulation knowledge check ≥80%
- practical job simulation ≥80/100
- 20-question final examination ≥80%

## Credential record fields

- credential ID
- recipient display name
- career and target role
- credential tier
- issue timestamp
- criteria version
- pathway version
- status (active / reissued / revoked)
- skills demonstrated
- final examination score where applicable
- practical simulation score where applicable
- public verification token

## Sharing

Credential detail pages provide:

- certificate view
- print/save PDF
- PNG export
- social graphic export
- LinkedIn credential field helper
- LinkedIn post templates
- copy credential ID/link

## LinkedIn
Capital Mastery is designed to use the issuing organization name **Capital Mastery** and a public credential verification URL. The learner enters the current LinkedIn certification fields using one-click copy helpers.
