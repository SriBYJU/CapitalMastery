# Zero-Cost Operations Pack

This folder contains the operational controls that are useful for Capital Mastery now, while it remains an unregistered project. Every control here uses the existing GitHub, Firebase and Cloudflare setup and does not require a vendor, employee or paid engagement.

| Document | Purpose |
|---|---|
| [Security threat model](security-threat-model.md) | Identifies protected assets, trust boundaries, credible threats, current controls and remaining limits. |
| [Production monitoring](zero-cost-monitoring.md) | Explains the automated health and bounded resilience checks. |
| [Recovery runbook](zero-cost-recovery-runbook.md) | Gives safe code and D1 recovery steps, including the destructive-restore guard. |
| [Incident response playbook](incident-response-playbook.md) | Gives a severity-based response process for outages, data exposure or integrity failures. |

These are engineering controls and evidence. They are not a SOC 2 report, legal advice, an external penetration-test attestation or a contractual service-level agreement.
